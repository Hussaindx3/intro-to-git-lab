GITHUB LAB

1. Does creating the repository in GitHub create the repo on your computer?

ANSWER: No, creating a repository on GitHub does not automatically create it on your computer.



2. What does cloning do?

ANSWER: Cloning a repository (git clone) downloads a full, working copy of an existing remote repository—including all of its files, branches, and complete version history—onto your local computer.



3. Once you've cloned the repo, how do you open it in VS Code?

ANSWER: To open a cloned repository in VS Code, you can use any of these methods depending on what you prefer:

From the terminal: Open your terminal, navigate into the cloned folder (cd folder-name), and type code . to open that directory directly in VS Code.

From VS Code itself: Open VS Code, go to File > Open Folder... (or File > Open... on macOS), and select the folder of the repository you just cloned.

Using the Command Palette: Press Ctrl + Shift + P (or Cmd + Shift + P on Mac), type Open Folder, and select your repository folder.
